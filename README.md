
# Short‑Term Quant Scanner

סורק כמותי למניות לטווח של 2–10 ימי מסחר.

## מה הוא בודק
- מומנטום 3/5/10 תקופות
- האצה במחזור (Volume Ratio, Z‑Score, Volume Acceleration)
- קרבה/פריצה של שיא 20 תקופות
- RSI(14)
- MACD Histogram + שיפוע
- ADX(14)
- ATR כאחוז מהמחיר
- חוזק הנר (Close Location)
- נזילות/מחזור כספי
- אישור שעתי אופציונלי
- Backtest היסטורי בסגנון Walk‑Forward

## פילוסופיית החלון
לצורך איתות יומי משתמשים בעיקר בנתונים מתגלגלים של 10–20 ימי מסחר.
לכיול היסטורי ברירת המחדל היא 6 חודשים בלבד — מספיק כדי לקבל דגימה,
אבל לא שנים של נתונים שעלולים להיות פחות רלוונטיים למשטר השוק הנוכחי.

לנתוני שעה, yfinance מאפשר נתוני Intraday עד 60 יום; ברירת המחדל באפליקציה היא חודש.

## התקנה
1. התקן Python 3.10+.
2. פתח Terminal בתיקייה.
3. הרץ:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## סימולים
- ארה"ב: NVDA, MU, AMD
- הונג קונג: 1196.HK
- אפשר גם להעלות CSV עם עמודה `ticker`.

## פירוש הציון
- 80–100: איתות כמותי חזק/נדיר
- 72–79: מועמד קנייה לבדיקה
- 64–71: מעקב
- מתחת 64: אין איתות

הציון אינו הסתברות מתמטית לרווח. לצד הציון מוצג `EmpiricalHitRate`,
שמודד כמה פעמים בעבר אירועים דומים הגיעו ליעד שהוגדר בתוך מספר הימים שהוגדר.

## הערה חשובה
Backtest על אותה תקופה שבה מכוונים את המשקולות עלול לגרום ל-overfitting.
כדי להתקדם למודל מקצועי, השלב הבא הוא:
1. לשמור כל איתות בזמן אמת למסד נתונים.
2. לא לשנות את האיתות לאחר שנוצר.
3. למדוד 30–100 איתותים Forward.
4. רק לאחר מכן לכייל משקולות/סף.
5. להוסיף Relative Strength מול המדד המקומי ו-Regime Filter של השוק.
